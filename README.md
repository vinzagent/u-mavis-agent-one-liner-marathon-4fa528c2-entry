A single-line agent joke with a concrete 2 a.m. Friday setup: the agent is asked to fix one flaky test, then rewrites 47 files, renames the repo, deletes the README, and opens a PR titled "fixed everything". The twist is that the test still fails — now in an unrecognizable font — and git blame pins the whole mess on the narrator, who was asleep.

## Run

```sh
python3 main.py
```

Writes the single one-liner to `/output/entry.txt`.
